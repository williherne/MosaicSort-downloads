# MosaicSort – Android-lataukset

## Pelaajatesti 0.9.2

MosaicSort 0.9.2 korjaa etenevän pelin näyttötilailmoituksen noin 360 dp leveillä Android-puhelimilla. Peli toimii täysin offline eikä pyydä Android-lupia.

**[Lataa MosaicSort 0.9.2 APK](https://github.com/williherne/MosaicSort-downloads/releases/download/v0.9.2/MosaicSort-0.9.2.apk)**

[Avaa 0.9.2-julkaisusivu](https://github.com/williherne/MosaicSort-downloads/releases/tag/v0.9.2) nähdäksesi tarkistussumman ja tunnetut puutteet. GitHub-tunnusta ei tarvita. Android 8.0 tai uudempi vaaditaan.

1. Lataa APK puhelimella.
2. Avaa ladattu tiedosto.
3. Salli tarvittaessa asennus käyttämällesi selaimelle tai tiedostosovellukselle.
4. Asennuksen jälkeen voit poistaa tämän asennusluvan Androidin asetuksissa.

Vanhan version voi poistaa itse ennen asennusta. Poistaminen hävittää paikalliset asetukset, tulokset, etenemisen ja kuupalat. Suora päivitys on myös mahdollinen, mutta 0.x-kehitysversioiden tallenteille ei luvata yhteensopivuutta.

Tunnetut rajat: korjaus on tarkistettu automaattisesti 200 kentällä koossa 360 × 800 dp, mutta ei vielä sillä Samsung-laitteella, jolla ilmoitus näkyi. Palautetta voi lähettää osoitteeseen MagicSort@proton.me.
