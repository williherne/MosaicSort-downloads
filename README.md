# MosaicSort – Android-lataukset

## Pelaajatesti 0.9.0

MosaicSort 0.9.0 on ennakkoversio pelaajapalautetta varten. Se sisältää Pasianssin, etenevän pelin, päivähaasteen, paikallisen Wall of Famen ja 50 kuupalan kertaluonteisen aloituslahjan. Peli toimii täysin offline eikä pyydä Android-lupia.

**[Lataa MosaicSort 0.9.0 APK](https://github.com/williherne/MosaicSort-downloads/releases/download/v0.9.0/MosaicSort-0.9.0.apk)**

[Avaa 0.9.0-julkaisusivu](https://github.com/williherne/MosaicSort-downloads/releases/tag/v0.9.0) nähdäksesi tarkistussumman ja tunnetut puutteet. GitHub-tunnusta ei tarvita lataamiseen. Android 8.0 tai uudempi vaaditaan.

1. Lataa APK puhelimella.
2. Avaa ladattu tiedosto.
3. Salli tarvittaessa sovellusten asentaminen vain selaimelle tai tiedostosovellukselle, jolla avasit APK:n.
4. Asennuksen jälkeen voit poistaa tämän asennusluvan käytöstä Androidin asetuksissa.

Jos haluat täysin puhtaan alun, poista vanha MosaicSort itse ennen asennusta. Poistaminen hävittää vanhan asennuksen kaikki paikalliset asetukset, tulokset, etenemisen ja kuupalat. Suora päivitys 0.8.0:n päälle on myös mahdollinen, mutta 0.x-kehitysversioiden tallenteille ei luvata yhteensopivuutta. Erillisen **MosaicSort kokeilu** -debugsovelluksen voi halutessaan poistaa erikseen.

Tunnetut rajat: tämä on testiversio. Oikean äänikirjan samanaikaista kuuntelua, kaikkia puhelinmalleja, TalkBackin koko käsikäyttöä ja pitkäaikaista pelaamista ei ole vielä kattavasti kokeiltu. Palautetta voi lähettää osoitteeseen MagicSort@proton.me.
